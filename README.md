# Cattucino Cat Cafe

Cattucino Cat Cafe is a cozy, interactive website for a fictional cat cafe. The website allows visitors to learn about the cafe, meet the cats, view upcoming events, explore the menu, and RSVP for events.

## Features

- Home page with a welcoming introduction to Cattucino Cat Cafe
- About section explaining the cafe
- Meet the Cats section with cat cards, images, names, and descriptions
- Events section showing upcoming cafe events
- Menu section with drinks, desserts, and special items
- RSVP form for visitors to sign up for events
- Form validation to make sure users enter valid information
- RSVP participant list that updates when someone signs up
- Personalized RSVP success message
- Success modal with an animated cat image
- Close button for the RSVP success modal
- Dark Mode / Light Mode toggle
- Scroll reveal animations for sections
- Navigation bar for moving around the website
- Contact and social media section
- Responsive layouts using Flexbox
